# Happy Birthday Swiss 🎂

## ใส่รูป

1. เตรียมรูป 2 ไฟล์
2. ตั้งชื่อไฟล์ให้ตรงเป๊ะ:
   - `swiss.jpg` → รูป Swiss
   - `couple.jpg` → รูปคู่
3. วางไฟล์รูปไว้ **โฟลเดอร์เดียวกับ** `index.html`

ถ้าอยากใช้ชื่อไฟล์อื่น หรือ `.png`/`.jpeg` ให้เปิด `index.html` แล้วแก้ 2 จุดนี้:
```html
<img src="swiss.jpg" ...>
<img src="couple.jpg" ...>
```

## ขึ้น GitHub Pages

1. ไปที่ github.com → **New repository** (public)
2. อัปโหลดไฟล์ทั้งหมด (`index.html`, `swiss.jpg`, `couple.jpg`) — ลาก-วางในหน้า "Add file → Upload files" ได้เลย
3. ไปที่ **Settings → Pages**
4. หัวข้อ Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที เว็บจะขึ้นที่:
   `https://<ชื่อ-user>.github.io/<ชื่อ-repo>/`

เสร็จแล้ว ส่งลิงก์นี้ให้ Swiss ได้เลย 🥂
